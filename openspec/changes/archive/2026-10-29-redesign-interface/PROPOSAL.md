# Proposal: Redesign da interface do Assistência TECH

## Why

A interface atual do Assistência TECH precisa de uma identidade visual mais profissional, consistente e moderna. O redesign busca melhorar a experiência de navegação, a legibilidade e a apresentação das funcionalidades para clientes e administradores, preservando o funcionamento existente.

## What Changes

- Estabelecer um sistema visual consistente, com cores, tipografia, espaçamentos, componentes e estados de interação padronizados.
- Redesenhar a página inicial para apresentar os serviços e direcionar os usuários às principais ações.
- Redesenhar a página de serviços, melhorando a organização e a apresentação das opções disponíveis.
- Aprimorar as páginas de login e cadastro, com formulários claros, validação visual e mensagens de feedback.
- Modernizar o painel administrativo e as páginas de clientes, equipamentos e ordens de serviço.
- Melhorar a adaptação das páginas para diferentes tamanhos de tela.
- Preservar as rotas, os fluxos existentes, a lógica de negócio e os pontos de integração planejados com o Xano.
- Manter os estados de carregamento, sucesso, erro e ausência de dados visualmente compreensíveis, conforme aplicável a cada funcionalidade.

## Capabilities

### New Capabilities

- `design-system`: identidade visual, componentes compartilhados e padrões de interação da interface.
- `responsive-interface`: adaptação da interface a diferentes tamanhos de tela.

### Modified Capabilities

- Nenhuma especificação existente será modificada nesta etapa, pois o projeto ainda não possui especificações registradas.

## Impact

- **Frontend:** páginas, componentes reutilizáveis, estilos e navegação do projeto Reflex.
- **Experiência do usuário:** apresentação e usabilidade das áreas públicas, de autenticação e administrativas.
- **Compatibilidade:** preservação das rotas existentes e dos fluxos funcionais.
- **Integração:** manutenção da compatibilidade com a futura integração ao Xano, sem presumir ou alterar contratos de API ainda não fornecidos.
- **Escopo:** o trabalho é focado na interface; alterações no backend e nas regras de negócio não estão incluídas, salvo necessidade identificada e aprovada posteriormente.
